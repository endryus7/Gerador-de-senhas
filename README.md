# 🔐 Gerador de Senhas

Aplicação web desenvolvida para gerar senhas aleatórias de forma rápida e segura.  
O usuário pode criar senhas fortes para utilizar em contas e serviços online.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
